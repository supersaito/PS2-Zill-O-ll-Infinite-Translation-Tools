# PS2-Zill-O-ll-Infinite-Translation-Tools
**IN MEMORY OF MC NORDAL (ERNESTO POVEDA)**
Hello, this is a guide made by me (saito) and MC Nordal (Ernesto Poveda) to help anyone to get
around with the tools of zill o'll infinite tools.

All the tools are of their respective owners, please don't post
them in public and use them giving us the credit for the tools.


1- First of all you need to install python 3.7 in your computer
for the decompressor/compressor.

If you try to execute it with another python version it will fail
or crash.

the folder big file main comp- decompressor contain our extractor of the
main script files inside res.rbb file.

Please read the readme inside that folder for further detail about
how to use it.

Reinserted files must be with the exact bytes or less than the original, otherwise the insertor will fail.


2.Script dumper reinsert folder contains the script extractor and reinsertor for .dat files.
As I said earlier it could potentially break the script file sometimes
while reinserting. Use it at your own risk. Also don't use it for system files, because it will surely break the file structure.

3.zill gfx tool folder contains our gfx converter, it converts and unswizzles  the qtx files into editable .tga and viceversa.

I hope that this small guide will help you to get around with the tools
to translate this fantastic game.
